# Siklon Seroja 2021 – respons laut di Laut Sawu dan selatan Nusa Tenggara

Kasus contoh Tugas Besar OSPAN (Oseanografi Pantai), FITB ITB. Lokasi 118–125° BT, 9–14° LS; periode Maret–Mei 2021.

- `scripts/b1_predictions.py`: prediksi a priori (B1), dikunci di commit pertama sebelum data diunduh.
- `scripts/0*_*.py`: unduh & olah data publik, dijalankan otomatis oleh GitHub Actions (`.github/workflows/data.yml`).
- `data/derived/`: data turunan (JSON) yang dibaca dashboard.
- `docs/`: dashboard Leaflet (GitHub Pages).
